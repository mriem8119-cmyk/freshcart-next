 # FreshCart E-commerce

An e-commerce web app built with Next.js (App Router), Tailwind CSS and Axios.

## Live Demo
https://freshcart-next-fawn.vercel.app

## Features
- Register, Login, Forgot Password, Change Password
- Homepage with slider, categories, offers and featured products
- Products, Product Details, Brands and Categories (with filtering)
- Cart, Wishlist, Checkout (cash and online), Orders

## Run locally
npm install
npm run dev
